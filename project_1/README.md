# Rock vs Mine Prediction 🎯

## 📌 Project Overview
This project uses Machine Learning to classify underwater objects as either a **Rock (R)** or a **Mine (M)** based on sonar data.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## ⚙️ How It Works
1. Load and explore the sonar dataset.
2. Prepare the input features and target labels.
3. Train a Machine Learning classification model.
4. Predict whether a new object is a rock or a mine using sonar measurements.

## 🚀 Example Output
- `R` → The object is a Rock.
- `M` → The object is a Mine.

## 🎓 Learning Objectives
- Understand Machine Learning classification.
- Practice data preprocessing and model training.
- Make predictions using new input data.
